The idea

Diagnose the gap from physics, never the reading

rᵢ  =  ( ymeasured − yphysics )  /  σchannel

A Mean Value Engine Model runs in lockstep with the engine, fed the same altitude, ambient conditions and throttle. Because the baseline has already absorbed altitude and derating, a healthy engine sits at r ≈ 0 across the whole envelope — sea level or 30,000 ft. Every model downstream sees residuals. None of them ever sees a raw sensor value.
